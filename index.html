Asado Crush

A simplified Candy Crush made in Java Swing by a team of three for the Programming Technology course at Universidad Nacional del Sur (2023). It runs in the browser thanks to CheerpJ. The game's text is in Spanish.

  • ← ↑ → ↓ move the cursor
  • W A S D swap with the candy above, left, below or right

The first load can take a while because it downloads a Java virtual machine. Click the game to use the keyboard. It needs a keyboard, so play it on a computer.

How to play

Pick a skin, then clear five levels with three lives for the whole game. Each level adds a new kind of candy and gives you less time or fewer moves: regular candies, cross-striped candies, frosting that breaks when something explodes next to it, a bomb you have to set off before its countdown ends, and jelly. Running out of time or moves costs a life and restarts the level.

How it's made

Java and Swing, with the game logic kept apart from the graphics. Board entities resolve swaps, matches and explosions through double dispatch, skins use the State pattern and levels are read from text files. Animations run on their own threads, coordinated by an animation manager.

By Martin Agnello, Maximo Fernandez and Agustín Villamil.
